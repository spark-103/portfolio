# 박세진 포트폴리오

기후테크·코딩·데이터 관리 활동을 소개하기 위한 포트폴리오 기획과 재사용 UI 컴포넌트입니다.

## 구성

- [제품 요구사항](./prd.md): 화면, 기능, 관리자 편집, 개발 및 검수 기준.
- [디자인 가이드](./design-guide.md): 색상, 글꼴, 버튼, 카드, 입력창과 모바일 규격.
- [메인 화면 예상 이미지](./homepage-preview.png).
- [이미지 생성 프롬프트](./homepage-preview-prompt.md).
- [컴포넌트 미리보기](./ui/index.html).
- [컴포넌트 사용법](./ui/README.md).

## 실행

저장소를 내려받은 뒤 `ui/index.html`을 최신 브라우저에서 엽니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

버튼, 배지, 교육 상태, 작업물 카드, 학습 카드, 입력창, 알림, 상단 메뉴, 하단 영역이 파일별로 나뉘어 있습니다. 공통 색상과 간격은 `ui/styles/tokens.css`에서 변경할 수 있습니다.

## 현재 구현 범위

현재 결과물은 기획 문서와 UI 컴포넌트 미리보기입니다. 관리자 로그인·데이터 저장·파일 업로드·실제 프로젝트 상세 화면은 후속 구현 대상입니다. 미리보기 카드의 콘텐츠는 실제 실적이 아닌 예시이며, 폼 입력은 저장하거나 전송하지 않습니다.

## 검증

자바스크립트 문법, 정적 파일 연결, 기본 컴포넌트 출력, 문자열 처리와 링크 형식을 확인했습니다. 실제 브라우저의 레이아웃·모바일 배치·사용자 상호작용은 아직 검증하지 못했습니다. 자세한 내용은 컴포넌트 사용법 문서를 참고해주세요.
